# akimai

akimai — прототип кредитного кабинета для предпринимателей. Пользователь отвечает на адаптивные вопросы о бизнесе и денежном цикле, получает ленту подходящих кредитных продуктов, а затем может отправить демо-заявку на рассмотрение эксперту.

Проект помогает выбрать финансовый инструмент под задачу бизнеса: кредитную линию, овердрафт, оборотное или инвестиционное финансирование, кредит под контракт и другие варианты.

> Важно: это демонстрационный прототип. Каталог предложений синтетический и помечен `unverified`. Сервис не отправляет заявки в банки, не обращается в БКИ и не принимает юридически значимых решений.

## Возможности

- адаптивная анкета с быстрыми ответами и отраслевыми ветками;
- отдельные сценарии для строительства, сельского хозяйства, контрактов, маркетплейсов и других видов бизнеса;
- подбор конкретных продуктов банка, а не только типов кредитов;
- прозрачный рейтинг с объяснением причин совпадения;
- Yandex AI для извлечения фактов из свободного ответа и осторожной корректировки стратегии;
- подача демо-заявки с таймлайном событий;
- фоновые проверки через worker;
- кабинет кредитного эксперта со статусами `under_review`, `needs_info`, `approved`, `rejected`;
- PostgreSQL для хранения анкет, продуктов, заявок и событий.

## Быстрый запуск

Требования: Docker Desktop с Compose v2.

```powershell
Copy-Item .env.example .env
docker compose up --build -d
```

После запуска откройте <http://localhost:8000>.

Проверить контейнеры и логи:

```powershell
docker compose ps
docker compose logs -f app
```

Остановить проект:

```powershell
docker compose down
```

PostgreSQL и демонстрационные данные создаются автоматически при первом запуске.

## Yandex AI

AI-слой необязателен: без ключа анкета продолжает работать по детерминированным правилам.

Заполните `.env`:

```dotenv
YANDEX_FOLDER_ID=your-folder-id
YANDEX_API_KEY=your-api-key
YANDEX_MODEL=aliceai-llm-flash
```

Затем пересоберите приложение:

```powershell
docker compose up --build -d
```

Не добавляйте `.env` в Git. В репозитории хранится только [.env.example](.env.example).

## Демо-сценарий

1. Откройте интерфейс и выберите отрасль, например «Строительство».
2. Укажите цель, сумму, срок, денежный цикл, юридическую форму и обеспечение.
3. Просмотрите ленту карточек продуктов и раскройте объяснение рейтинга.
4. Нажмите «Подать демо-заявку» и отправьте синтетические контактные данные.
5. Дождитесь перехода заявки в `На рассмотрении` или `Нужны уточнения`.
6. Откройте «Демо-кабинет эксперта» и войдите:

   - логин: `reviewer_demo`
   - пароль: `reviewer-2026`

7. В очереди эксперта запросите уточнение, одобрите или отклоните демо-заявку.

## API

Основные маршруты:

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/api/health` | проверка сервиса |
| `GET` | `/api/questionnaire` | версия анкеты и вопросы |
| `POST` | `/api/intake/start` | новая сессия анкеты |
| `POST` | `/api/intake/{session_id}/message` | ответ на текущий вопрос |
| `POST` | `/api/match` | подбор и сортировка продуктов |
| `POST` | `/api/applications` | создание демо-заявки |
| `GET` | `/api/applications/{id}` | статус и таймлайн заявки |
| `POST` | `/api/demo/login` | вход в демо-роль |
| `GET` | `/api/reviewer/applications` | очередь эксперта |
| `POST` | `/api/reviewer/applications/{id}/transition` | изменение статуса |

Полная спецификация находится в [`submission/openapi.yaml`](submission/openapi.yaml), описание сценариев — в [`submission/api.md`](submission/api.md). Коллекция для Postman — [`submission/postman_collection.json`](submission/postman_collection.json).

## Как считается совпадение

Сначала применяются жёсткие фильтры: цель, сумма и подходящее обеспечение. Затем продукты сортируются по объяснимому баллу:

- соответствие финансового инструмента — до 35 баллов;
- денежный цикл и этапность расходов — до 20;
- соответствие каталогу и профилю бизнеса — до 20;
- нагрузка платежа — до 15;
- скорость оформления — до 5;
- ограниченный AI-бонус — до 5.

Подробные правила и примеры находятся в [`submission/decision_rules.md`](submission/decision_rules.md) и [`docs/questionnaire.md`](docs/questionnaire.md).

## Проверка

Unit-тесты:

```powershell
python -m unittest discover -s tests -v
```

Браузерный smoke-тест:

```powershell
$env:PLAYWRIGHT_CORE_PATH = Join-Path $env:TEMP 'akimai-browser\node_modules\playwright-core'
node scripts/browser_smoke.js
```

Smoke-тест проверяет отраслевые подсказки, полный путь анкеты, ленту продуктов, подачу заявки, worker-статусы, мобильную ширину, пустую выдачу и очередь эксперта.
